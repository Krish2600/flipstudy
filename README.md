# FlipStudy ⚡ | Interactive Flashcard Study Application

A fast, interactive, client-side web application for flashcard-based study and self-assessment, covering JavaScript, Web APIs, and CSS concepts.

🌐 **Live Demo**: [https://flipstudy-three.vercel.app/](https://flipstudy-three.vercel.app/)

---

## ✨ Features

* **3D Card Flip Animation**: Smooth CSS 3D transform transitions for revealing answers.
* **Topic Filtering**: Filter flashcards by subject category (JavaScript, Web APIs, CSS, All Topics).
* **Mastery Tracker**: Live progress counter tracking cards marked as "Known" vs. "Needs Review".
* **Fisher-Yates Shuffle**: Randomize deck order for effective studying.
* **Keyboard Accessible**: Full keyboard navigation support (Space / Enter to flip cards).
* **Responsive Layout**: Fluid CSS Grid layout adapting automatically to desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, Vanilla CSS3 (Custom design system with dark mode aesthetics), Modern ES6 JavaScript.
* **Build / Dev Server**: Vite for ultra-fast local development and static bundling.

---

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+)

### Development

1. Open a terminal in the `flashcards` directory:
   ```bash
   cd flashcards
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Open the displayed local URL (typically `http://localhost:5173`) in your web browser.

### Production Build

To build the static production assets:
```bash
npm run build
```

To preview the built production app locally:
```bash
npm run preview
```
